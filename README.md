# Gym Bulldogs Old School

Sistema de administración para gimnasio, en donde la administració|n puede registrar horarios, asignar rutinas, así como llevar una registro de socios. Quienes a su vez, pueden consultar su información y rutinas, también pueden consultar el avance que han tenido durante el tiempo que han estado asistiendo al gimnasio.
